Sources de temps intégrées

Time Source Constant
Constant Description Valeur
time_source_global La Time Source globale 0
time_source_game La Time Source jeu 1

Vous pouvez utiliser la Time Source globale ou la Time Source jeu comme parent pour votre Time Source personnalisée. Les deux Time Sourcesont disponibles globalement.

La Time Source globale s'exécute en dehors de la boucle principale du jeu, tandis que la Time Source jeu s'exécute dans le cadre de la boucle du jeu.

Le choix entre Global et Jeu n'affecte pas l'influence des Time Sourcesur le taux de rafraîchissement de votre jeu ; cela dépend de l'unité que vous utilisez.

Commandez

LesTime Sourcehéritant de la Time Source globale sont traitées avant la Time Source du jeu.

États

La Time Source jeu a des états, ce qui signifie qu'elle peut être paused. La Time Source globale n'a pas d'états et ne peut pas être mise en pause.

Vous pouvez utiliser la Time Source globale pour les minuteries qui doivent être exécutées indépendamment de l'état du jeu, et la Time Source jeu pour les minuteries qui sont liées à votre boucle de jeu principale. Vous pouvez ensuite mettre en pause tous vos timers liés au jeu en mettant en pause la Time Source du jeu.
